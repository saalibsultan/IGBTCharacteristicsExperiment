IGBT Characteristics Experiment

Practical power electronics lab experiment to test and analyze the switching behavior and operational characteristics of an IGBT module using training panels and multimeters.

Hardware components:
- Modular trainer panel with IGBT (1000V / 15A) and load resistor blocks (100 ohm and 300 ohm sections)
- Digital multimeter for current measurement (mA scale)
- Signal/pulse generator for gate triggering
- Connection jumper wires

Laboratory wiring steps:
1. Load Setup: Set up the resistance path from left to right across the designated resistor blocks according to lab requirements.
2. Multimeter Connection: Connect the load endpoint to the multimeter positive terminal (set to mA range), and route the meter's negative terminal back to the negative ground supply.
3. Power Lines: Connect the main power lines by reversing the top and bottom supply routing compared to the TRIAC setup, following the IGBT module layout.
4. Gate Connection: Run a jumper wire from the pulse generator directly to the IGBT gate (G) terminal for switching control.

Verification:
Monitor the current readings on the multimeter and observe the switching response and voltage characteristics across the load terminals.
